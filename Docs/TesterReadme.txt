KRPKNKOFF - tester build
========================

This is a private test build. It is licensed to you personally: please do not share it, upload it or stream it
without asking. Your name is shown on screen while you play.

INSTALL
1. Unzip the whole folder anywhere (keep the folder structure).
2. Run KRPKNKOFF.exe.
   - Windows may show "Windows protected your PC" (the game is not code-signed): "More info" -> "Run anyway".
   - Missing DLLs (VCRUNTIME / MSVCP): run Engine\Extras\Redist\en-us\vc_redist.x64.exe once.
3. Windows 10/11 64-bit, DirectX 12 graphics card, ~3 GB disk. Laptops: see GRAPHICS below.

ACTIVATION (first start)
1. The game shows your MACHINE CODE (like ABCD-EFGH-JKLM-NPQR). Press Copy and send it to the developer.
2. You get a license key back (a long line of text). Copy it, press Paste in the game, then Activate.
3. The key works on this PC only and until its expiry date. A new key is needed after reinstalling Windows or
   changing the system drive. If it stops working, send the developer the message the activation screen shows.
4. The game checks online at start whether your license is still active. You can play offline, but it has to
   reach the internet at least once every 7 days.

FEEDBACK
  Your game writes a short log here (damage / contact events, settings): include it with bug reports:
  %LOCALAPPDATA%\KRPKNKOFF\Saved\Logs\KartTester.log

CONTROLS (keyboard / Xbox pad)
  Throttle / brake   W / S        Steer            A / D
  Clutch             Left Shift   Shift up / down  E / Q (KZ gearbox)
  Starter / push     B / hold P   Reset + repair   R
  Camera             C            Telemetry        T
  Quick setup        Tab          Menu             Esc
  Jetting            [ / ]        Weather N / rubber M

GRAPHICS / LOW FRAME RATE
  Esc > Settings > GRAPHICS: Quality (Low / Medium / High / Epic), Render scale, Frame limit, Show FPS.
  Laptops with two GPUs: Windows Settings > System > Display > Graphics > add KRPKNKOFF.exe
  (KRPKNKOFF\Binaries\Win64) > High performance, and plug the charger in.
